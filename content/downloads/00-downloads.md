# ダウンロード

小講堂でそのまま使えるファイルです。今回のショーのファイルそのものではなく、次の担当者が自分のショーを作り始めるときの土台になるものに絞りました。各ファイルの前提と、確かめていないことも書いておきます。

## 照明

### DMX アドレスの表

小講堂の既設の灯体です。QLC+ 以外のソフトでも使えるように、表にしました。同じ内容を [CSV](files/lighting/small-auditorium-dmx.csv) でも配っています。アドレスはすべてユニバース1です。

{{dmx_table}}

「状態」は次の意味です。「本番で使用」は今回の本番で点けたもの、「点かない」は今回点かなかったもの、「未使用（状態未確認）」は今回使わず、点くかどうかを確かめていないものです。点かない灯体も、アドレスが分かるように表に残しています。電球の交換などで直ったら、そのまま使えます。

ボーダー01は、舞台の上方に電球が複数並んだ灯体です。電球が少しずつ切れていくので、使っているうちに光量が落ちます。

サスライトは5台です。名前の付いた4台のアドレスは4・5・6・9番で、3/5 は7番か8番のどちらかだと考えられますが、記録からは決めきれていません。どちらも今回は点きませんでした。

使う前に確かめることが3つあります。

- 会場の DMX 端子は XLR 5ピンです。DMX の USB 変換器の出力がこれと合うか確かめてください。ワークスペースの出力は「DMX USB」の1本目にしてあります。手元の変換器に合わせて、QLC+ の入出力の画面で選び直してください。
- カラー LED のアドレスは灯体側でも設定します。過去の記録では、パネル型の灯体が3台ずつ同じアドレスにまとめられた状態になっていて、公演ごとに分け直していました。仕込みの日の朝に、灯体のアドレスがこの表と合っているかを確かめてください。
- ワークスペースは QLC+ 5.3.0 の形式です。QLC+ 4 で開けるかは確かめていません。Capture の CSV の機種名と位置は、Capture の上で近いものを選んで置いたもので、実際の機種や実測の位置とは限りません。

## 音響測定

[REW](https://www.roomeqwizard.com/)（無料の音響測定ソフト）で開ける測定データです。小講堂で持ち込みのスピーカー（Bose F1 Model 812 と F1 Subwoofer を左右に1組ずつ）を鳴らして測りました。

| ファイル | 中身 |
|---|---|
| [2026-11-06-rear-center-initial.mdat](files/audio/rew/2026-11-06-rear-center-initial.mdat) | 11月6日、客席最後方の中央。途中から返しスピーカーの音も混ざっている |
| [2026-11-07-center-f1.mdat](files/audio/rew/2026-11-07-center-f1.mdat) | 11月7日朝、客席中央の1席。左だけ、右だけ、左右両方を、それぞれ3回ずつ |
| [2026-11-07-center-eq-trials.mdat](files/audio/rew/2026-11-07-center-eq-trials.mdat) | 11月7日夜、同じ席で EQ を変えながら測った8回分。1〜2回目は55Hz を持ち上げた状態、3〜4回目は持ち上げない状態、5〜6回目は43Hz と61Hz を下げた状態、7〜8回目はさらにサブウーファーの音量を10時から12時の位置に上げた状態 |

どの測定にも、43Hz 前後と61Hz に山があり、50Hz 前後に谷がありました。ただし、これが部屋のせいなのか、スピーカーや置き方のせいなのかは、1席だけの測定では分けられていません。次に測るときは、客席の2〜3席で測ると原因を切り分けられます。

測定マイクは dbx RTA-420 v2 で、マイクごとの校正データはありません。音圧の値は、スマートフォンの騒音計アプリの表示に合わせて REW で校正したものです。絶対的な音圧としてではなく、同じ日の測定どうしを比べる目安として見てください。
