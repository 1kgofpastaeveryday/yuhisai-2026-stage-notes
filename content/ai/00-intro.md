# AIエージェントでステージを動かした記録

雄飛祭2026の小講堂のステージでは、学生1人が音響・照明・再生操作・撮影の支援を担当し、その準備と運用の大部分に AI エージェントを使いました。使ったのは Claude Code と Codex です。このページは、AI エージェントを実際の仕事に使う人に向けて、役割の分け方、作ったもの、確かめ方、うまくいったこと、そして AI の誤りを記録したものです。ステージの手引きは「[小講堂でステージを担当する人へ](./)」、準備の記録は「[作業記録](record.html)」にあります。

元にしたのは、担当者（筆者）と AI エージェントの会話ログです。ログから事実を抜き出し、Gemini で文章にした後、Codex が一文ずつ元の材料と照らし合わせて直しました。照合した3,949文のうち1,277文に、材料とのずれがありました。直した後の文章も、照合は1回だけです。

本文では、AI が報告しただけで確かめていないことは、事実として書いていません。担当者は「担当者」、AI は Claude、Codex のように書いています。
