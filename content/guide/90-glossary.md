## 用語集

本文に出てくる用語の一般的な意味です。この節だけは記録からではなく、担当者（筆者）側で説明を書き足しました。

### 音響

| 用語 | 意味 |
|---|---|
| PA | 会場で声や音楽を大きくして客席に届ける音響の仕組み全体。スピーカー、アンプ、ミキサーなどからなる |
| ミキサー | 複数のマイクや再生機の音を受け、音量や音質を調整して混ぜ、スピーカーへ送る機器。卓とも呼ぶ |
| オーディオインターフェース | パソコンとマイク・スピーカーの間で音の信号をやりとりする機器。今回は RME Babyface Pro FS を使った |
| TotalMix、TotalMix Remote | RME のオーディオインターフェースの内部ミキサーを操作するソフトと、それを iPad などから遠隔操作するアプリ |
| サブウーファー | 低い音を受け持つスピーカー |
| 返し（モニタースピーカー） | 舞台上の出演者が自分たちの音を聞くために、舞台側へ向けて置くスピーカー |
| XLR | マイクや業務用音響機器で使う、3ピンの丸い端子とそのケーブル。照明の DMX では5ピンのものも使う |
| RCA | 家庭用のオーディオ機器で使う、赤・白などの丸い端子 |
| SPL | 音圧レベル。音の大きさを dB（デシベル）で表した値 |
| GEQ | グラフィックイコライザー。周波数帯ごとに音量を上げ下げして音質を整える機能 |
| リミッター | 音量が決めた値を超えないように抑える機能。スピーカーや耳を守るために使う |
| REW | Room EQ Wizard。測定マイクで部屋やスピーカーの音響特性を測る無料のソフト |
| ピンクノイズ | 音響測定に使う、全帯域にわたるザーという雑音 |

### 照明

| 用語 | 意味 |
|---|---|
| DMX | 舞台照明の機器をつなぎ、明るさや色を送るための規格。1本のケーブルに複数の灯体をつなぎ、アドレスで区別する |
| DMX アドレス | 1本の DMX の線の上で、各灯体がどの番号の信号を受けるかを決める設定 |
| 灯体 | 照明器具1台のこと |
| QLC+ | パソコンで照明を操作する無料のソフト |
| ムービングライト | 向きをモーターで動かせる照明 |
| ヘイズ | 光の筋を見せるために空間に薄く漂わせる煙 |

### 再生・制御

| 用語 | 意味 |
|---|---|
| Ableton Live | 音楽制作と演奏に使うソフト。今回は音源の再生と、照明への合図の送出に使った |
| DAW | 音楽制作ソフトの総称。Ableton Live もその一つ |
| Arrangement、Session | Ableton Live の2つの画面。Arrangement は時間軸に沿って並べて再生し、Session はクリップを個別に起動する |
| MIDI | 音楽機器やソフトの間で、音符や操作の合図を送る規格 |
| Ableton Link | 複数の機器やソフトのテンポをネットワーク経由でそろえる仕組み |
| TouchOSC | スマートフォンやタブレットに操作画面を作り、ネットワーク経由でソフトを操作するアプリ |
| BPM | 1分あたりの拍の数。曲のテンポ |

### ネットワーク・パソコン

| 用語 | 意味 |
|---|---|
| ポート | パソコンが通信の相手を区別するための番号。特定の番号を止められると、それを使うサービスにつながらない |
| 802.1X、WPA2-Enterprise | 大学や企業の Wi-Fi で使う、利用者ごとのアカウントで認証する方式 |
| VPN | 通信を暗号化した経路を通して、別のネットワークにいるようにつなぐ仕組み |
| Tailscale | 離れた場所にある自分の機器どうしを、VPN のようにつなぐサービス |
| Parsec | 別のパソコンの画面を遠隔で表示し、操作するソフト |
| SSH | ネットワーク経由で別のコンピュータを安全に遠隔操作する仕組み |
| テザリング | スマートフォンの携帯回線を、ほかの機器のインターネット接続に使うこと |
| WAN | ルーターから見た外側の回線。インターネットにつながる側 |
| DNS、名前解決 | 機器やサイトの名前から、通信先の番号を調べる仕組み |
| TB4 | Thunderbolt 4。今回は Mac と Windows パソコンをケーブルで直接つなぐのに使った |
| ハッシュ照合 | ファイルから計算した値を比べて、コピーしたファイルが元と同じかを確かめること |
| Git | ファイルの変更履歴を残すための仕組み |
