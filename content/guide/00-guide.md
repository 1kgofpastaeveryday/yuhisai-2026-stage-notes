# 小講堂でステージを担当する人へ

小講堂のステージで、持ち込みの音響・照明を使う人のための手引きです。雄飛祭2026（本番は11月7日・8日）で、学生1人が持ち込みの機材で音響・照明・再生操作・撮影の支援を担当しました。そのときの記録から、次の担当者が使える形に組み直しています。

上から順に、会場の条件、準備の段取り、当日の人の配置、機材、費用、連絡のやり方の順に並べました。各項目の根拠と経緯、起きた失敗の全件は「[作業記録](record.html)」にあります。小講堂の照明の灯体パッチ（QLC+）と音響の測定データは「[ダウンロード](downloads.html)」から取れます。AI エージェントの使い方は「[AIエージェントの記録](ai.html)」にまとめました。

書き方の約束です。確かめた事実は言い切ります。今回の記録から考えたことは「〜とよい」「勧めます」と書き、確かめていないことは「未確認」と書きます。個人の名前は出さず、実行委員会、大学の事務課、レンタル業者のように役割で書きます。出演団体と担当者の所属（放送研究会）は、団体名で書きます。

## 最初に知っておくこと

影響が大きかった条件を5つ挙げます。どれも、今回は準備の途中で知って、計画を変えることになりました。

1. 学生が運転する車は大学の構内に入れず、周辺の路上にも止められません。機材は近くの駐車場から人の手で運びます。今回のスピーカー一式だけで約90kgありました。
2. 客席の照明（客電）は、既設の調光卓の物理スイッチでしか操作できません。パソコンで照明を制御しても、調光卓に1人要ります。
3. 調光卓の位置では、PA の音が客席より10dBほど小さく聞こえます（担当者の体感で、測った値ではありません）。そこで音量を合わせると、客席では大きすぎます。測定マイクを客席に置き、音圧（SPL）の数値を見ながら音量を決めてください。担当者（筆者）は本番を終えて、数値を見ていなければ110dB ほどまで上げかねなかったと振り返っています。
4. コンセントは、まとまった1回路あたり10Aまでです。
5. 大学の Wi-Fi では端末どうしが通信できない場合があり、特定のポートも制限されています。壁の有線 LAN の口は塞がれています。

| 大学の Wi-Fi | 端末どうしが通信できない場合がある。特定のポートが制限され、外部のサービスに届かないことがある。2.4GHz の WPA2-Enterprise（利用者ごとの認証） | 担当者の確認 |
| 低音 | 40〜60Hz が強く響き、狭い帯域の EQ ではあまり変わらなかった。原因は特定していない。2日目に確定した設定の音が一番よかった。低音はぼやけたままだったが、体に響く低音があるほうが楽しく、客席も1日目より盛り上がった。低音の濁りを取ろうとして削りすぎないほうがよい | 客席後方の測定と担当者の聴感 |

2階の照明が禁止になるまでの経緯です。最初、放送研究会は広告研究会に「動かしても、戻してもらえればよい」と伝えていて、実行委員会もそれを黙認していました。広告研究会がリハーサルで照明を動かしたまま戻さなかったので、担当者（筆者）が実行委員会に連絡し、そこから移動は全面的に禁止になりました。向きは担当者（筆者）が直しましたが、中央に寄せすぎていて、1日目は舞台の左右両端の手前が暗くなりました。2日目に照明を広げて（ズームアウトして）直しています。ほかの団体と共用する設備は、動かしてよいか、誰がいつ戻すかを最初に決め、本番の前日に向きを確かめてください。

## 3. 当日の人の配置

今回は担当者1人に操作が集中し、離席も交代もできませんでした。次回は、少なくとも次の役割を分けることを勧めます。

| 役割 | 場所 | やること |
|---|---|---|
| PA（音量の調整） | 客席の最後方 | iPad などからミキサーを遠隔操作し、客席の音と音圧（SPL）の数値の両方を見ながら音量を合わせる |
| 客電 | 調光室の調光卓 | 演目の始めと終わりに、客席の照明を物理スイッチで操作する |
| 再生と照明の操作 | 調光室 | 曲出し、停止、音量、緊急時の照明を操作する。この4つと曲順をA4の紙1枚にまとめ、交代する人も本番の機材で練習しておく |
| 搬入・撤収 | 駐車場と小講堂の間 | 運搬、スピーカーの組み立て、床の配線。今回の記録では、補助に2人ほど要るという見立てがある |

設営の判断は前日までに済ませます。今回のリハーサルでは、現場で一から判断しながら組み立てたため、何から手を付けるか分からなくなりました。ケーブルの両端に行き先のラベルを貼り、置き場所ごとに機材を箱に分け、設営の手順を表にしておくと、補助の人にも頼めます。

本番中に、イントロの前に誤ってメトロノームを鳴らしたことと、プロジェクターの不具合に気を取られて撮影を始め忘れたことがありました。どちらも、人が覚えておくのではなく、仕組みで防げます。本番を始めるボタン（今回は TouchOSC の開始ボタン）を押したときに、メトロノームを必ず切るようにします。撮影も、同じボタンで自動的に始まるようにします。今回はどちらも作っていないので、使うカメラが外から録画を始められるかは確かめてください。仕組みにできないもの（2階からの照明の向き、操作端末がつながっているかなど）は、紙の一覧にして手元に置き、本番前に目で確かめます。仕組みにしたものも一覧に入れておくと、仕組みが動かなかったときに気づけます。

マイクを使う出演団体には、マイクを返しスピーカーに向けないよう、本番前に伝えてください。今回は、演者がマイクを返しスピーカーに向けてハウリングした場面がありました。

転換の時間は短く、今回の予定には転換用の余白がありませんでした。返しスピーカーを転換のたびに動かすなら、誰が、どの経路で、何分で動かすかを、転換のリハーサルで確かめてください。

機材については、次の3つを勧めます。

既設の機材は、使う前提にする前に現物を確かめてください。返しスピーカーは、アンプと端子があったので使えると考えていましたが、本体がありませんでした。

構成を変えたら、機材表、配置図、手順書を同時に直してください。スピーカーの配置を変えた後も古い資料が残り、古い構成のまま案内されたことがあります。

レンタル業者の受取・返却の条件は、案内のページを最後まで読んで確かめてください。今回は、ページの前半だけを読んで返却時刻を誤解したことがありました。返却の拠点は受取の拠点と別で、ビルの7階まで運ぶ必要がありました。

## 5. 費用と分担

今回のレンタル費用と分け方です。

| 項目 | 金額 |
|---|---|
| メインスピーカーのセット | 24,640円 |
| 返しスピーカー2台 | 9,504円 |
| 補償料（レンタル料の10%） | 4,945円 |
| ケーブル、ケーブルプロテクター、測定マイクを含めた合計 | 54,401円（3日間） |
| 放送研究会の負担 | 10,000円 |
| 4団体で分担した額 | 44,401円 |

分け方は、1団体ごとの基本料3,638円に、出演枠の長さに比例した額を足す方式にしました。最初は利用する団体で均等に割る案でしたが、大学側から利用時間や人数に応じて差をつけるよう意見がありました。集金は、実行委員会が合同説明会で各団体から集める形にしてもらいました。

費用で気をつける点です。

- レンタル料は、品目、日数、税込みか税抜きかを組にして控えます。1日料金を2日分と読み違えたことがあります。
- 補償は、免責が5,500円になる代わりに、置き忘れ、紛失、盗難、天災は対象外でした。私物の機材は、自分の保険の上限と対象外の条件を確かめてください。
- 金額を知らせた後に増えたら、理由と各団体の増額分を一緒に伝えます。
- 分担の資料を直したら、公開した先で団体数と金額を確かめます。手元で直しただけで、公開されたページは古いままだったことがあります。

## 6. 連絡と記録のやり方

関係者が多く、連絡の行き違いが繰り返し起きました。効いたやり方を挙げます。

- 下書き、送信、相手の返事を分けて記録します。下書きを送信済みと思い込んだことも、送信済みを未送信と思い込んだこともありました。
- 送る前に、本文、数量、条件を確定させます。業者への依頼には、機材名、数量、利用日、受取と返却の日時、まだ決まっていない条件を書きます。
- 連絡は、相手の回答期限と次の判断に要る項目に絞ります。確認事項を全部入れた文面は、約2,000字になりました。
- 許可は、実際の返事と照らし合わせて記録します。アンケートの未回答を了承と数えないでください。
- 機材の持ち主や企画の経緯を、交渉のために事実と違う形で書かないでください。
- 出演団体が自分で作業するのか、ステージ担当に頼むのかを分けて聞きます。
- 音源は、圧縮していない WAV や AIFF で受け取ります。元が MP3 などなら、そのまま受け取り、動画から抜き出したり圧縮し直したりさせないでください。本番2日目に、画面録画で二重に圧縮された音源が見つかり、7曲を作り直しました。曲順、始め方と終わり方、曲間の秒数、合図を出す人も一緒に受け取ります。

## 7. 来年以降に向けて

継続して小講堂でステージを組むなら、私物に頼らない形を考える必要があります。今回は担当者の私物と放送研究会の備品を多く使ったので、すべてレンタルで揃えた場合の参考額を出しました。結果は約13万〜15万円で、当時の団体の分担額（38,170円）はその25〜30%ほどでした。代替の機種を含む試算で、同じ条件で予約できるかは確かめていません。

大学の資金で機材を買う、放送研究会の備品にする、といった相談は、今回の実績をもとにできる可能性があります。大学職員が前向きだったという担当者の報告はありますが、予算化は決まっていません。
