# 画面内の文言の変更

2026-10-25。`stop-describing-ui`に沿って、操作名と必要な制約の表示に絞った。操作手順と未設定の項目はREADMEと運用資料に記載する。

| 変更前 | 変更後 |
|---|---|
| SHOW CONTROL／雄飛祭2026 / マニピュレーター | 雄飛祭2026 |
| UI PROTOTYPE／プレビュー・外部送信なし | 試作　送信OFF |
| 演目を選択／12演目 / 各3〜4曲 | 演目 |
| 4曲を開く | 4曲 |
| 曲を頭出しして、下の「続きから再開」を押す | 曲を頭出し |
| この曲の頭へ移動／頭出し | 頭出し |
| 頭出しの選択（プレビュー）／選択した曲 | 表示枠を削除。曲のボタンの枠と背景で示す |
| 未選択 / 現在位置から続行 | 表示枠とともに削除 |
| 続きから再開／Liveの現在位置から進む | Live 続きから再開 |
| 照明の残りを止める / 音源はそのまま | 削除 |
| 再開をプレビューしました／QLC+全停止をプレビューしました | 削除 |
| 演目一覧 | 左向きの戻るアイコン |

「試作　送信OFF」は、操作しても外部アプリが動かないことを見落とさないために残した。曲と演目のボタンの強調は、画面で最後に選んだ曲を示し、Liveから受信した状態ではない。ボーダーのON／OFFも操作名であり、現在の点灯状態を示す表示ではない。
